# Capstone Project 26T2 T13C Cake

This is the repository for the COMP9900/COMP3900 capstone project.

## Branch Strategy

- `main`: stable branch for final and reviewed code
- `dev`: development integration branch
- `feature/*`: feature branches for individual tasks

## Development Workflow

1. Pull the latest code from `dev`.
2. Create a new feature branch.
3. Commit and push your changes.
4. Open a Pull Request to merge into `dev`.
5. After testing, merge `dev` into `main` through a Pull Request.
